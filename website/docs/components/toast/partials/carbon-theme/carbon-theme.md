## Different color values

HDS supports a `highlight` color, which is used to draw attention to new features, beta features, changes, and similar updates. Carbon doesn't have a direct equivalent, but supports an `info` color, which sits differently in the visual hierarchy.

In the HDS theme, the `highlight` Toast uses values from the purple core palette. In the Carbon themes, these values are mapped to the blue `info` palette, resulting in a different visual appearance that may change how much they stand out on the page.
