## Interactivity

In the Helios Stepper Nav component, each step is an interactive element, while in the Carbon Progress Indicator component (the closest equivalent), only the title of the step is interactive and is presented visually as a link.

When using a Carbon theme, the Helios Stepper Nav maintains the same interactive behavior as the HDS theme, with the entire step remaining interactive, but the step title is styled to visually match the link styling of the Carbon Progress Indicator.
