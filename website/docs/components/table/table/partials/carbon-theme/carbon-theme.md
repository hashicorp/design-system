## Interactive elements in column headers

In the Carbon Data Table component, the entire column header is interactive and is used to handle sorting and similar functionality.

When using a Carbon theme, the interactive elements in HDS Table column headers remain buttons nested within the header cell, and the header cell itself is not interactive. Sorting buttons and tooltips are still visually distinguishable as interactive elements.
