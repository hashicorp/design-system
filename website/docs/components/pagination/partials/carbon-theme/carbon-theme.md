## Pairing with a Table or data set

Carbon supports multiple pagination components: Pagination (the default) and Pagination Nav. These components vary in their visual appearance with the default Pagination component leveraging a more "containerized" appearance.

The Carbon theme of the Helios Pagination component draws visual aspects from both Carbon components depending on the variant:

- HDS Pagination Numbered: closer in visual appearance to Carbon's Pagination Nav
- HDS Pagination Compact: closer in visual appearance to Carbon's default Pagination

This will impact how Pagination is paired with a [Table](/components/table/table), [Advanced Table](/components/table/advanced-table), or other data set.
