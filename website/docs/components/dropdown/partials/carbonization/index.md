## ToggleButton secondary muted color

For the `ToggleButton`, the `@color` argument supports a value `secondary-muted`. This variant is visually identical to the `secondary` color for HDS themes, but differs for Carbon themes. Use the `secondary-muted` color to have a secondary toggle button on Carbon themes which is less visually dominant.
