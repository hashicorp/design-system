The [Helios Design Tooling Figma Plugin](https://www.figma.com/community/plugin/1572365910132690910) helps you create, assess, and work more efficiently with HDS Figma assets. Use it to automate repetitive design tasks, compare migration changes, and update service icon colors.

## Get started

1. Open the [Helios Design Tooling Figma Plugin](https://www.figma.com/community/plugin/1572365910132690910) from the Figma Community.
2. In a Figma file, open the **Plugins** menu and select the **From IBM** sub-menu.
3. Alternatively, open the Figma actions menu (`cmd/ctrl + k`) and search "HDS Design Tooling".

## Feedback and requests

Use **Submit Feedback** in the plugin to report an issue, share feedback, or request a workflow improvement. Include the feature you used, the Figma context, what you expected, and what happened to explain the issue.

For feature requests, describe the repeated task, the current friction, who benefits, and the desired outcome.
