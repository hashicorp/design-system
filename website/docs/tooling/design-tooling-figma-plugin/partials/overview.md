The [Helios Design Tooling Figma Plugin](https://www.figma.com/community/plugin/1572365910132690910) helps you create, assess, and work more efficiently with HDS Figma assets. Use it to automate repetitive design tasks, compare migration changes, and update service icon colors.

## Get started

1. Open the [Helios Design Tooling Figma Plugin](https://www.figma.com/community/plugin/1572365910132690910) from the Figma Community.
2. In a Figma file, open the **Plugins** menu and select the **From IBM** sub-menu.
3. Select **HDS Design Tooling**.

Alternatively, open the Figma actions menu (`cmd/ctrl + k`) and search for "HDS Design Tooling."

Enable the [HDS Foundations v2.0](https://www.figma.com/design/uX4OEaJQdWfzULADchjAeN/HDS-Foundations-v2.0?m=auto&node-id=2916-4&t=CgmhOUsHyOKRtyaL-1), [HDS Components v2.0](https://www.figma.com/design/iweq3r2Pi8xiJfD9e6lOhF/HDS-Components-v2.0?m=auto&node-id=2-7&t=2zYgbCFKY0ibOrWl-1), [HDS Patterns v2.0](https://www.figma.com/design/5Pv32j4QiOOD8lkFTD1dxC/HDS-Patterns-v2.0?m=auto&node-id=2-45&t=PbbBtIfzmCoSWglS-1), and [HDS Icons](https://www.figma.com/design/TLnoT5AYQfy3tZ0H68BgOr/HDS-Icons?m=auto&node-id=164-0&t=2SV6iizqmgRpPLZ8-1) libraries in your project before using the plugin.

## Feedback and requests

Use the **Submit Feedback** link in the plugin to report an issue, share feedback, suggest a workflow improvement, or request a new feature. Include the feature you used, the Figma context, what you expected, and what happened to explain the issue.

For feature requests, describe the repeated task, the current friction, who benefits, and the desired outcome.
